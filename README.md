# Disable Camera Diplomacy Focus

A Total War: WARHAMMER III mod that stops the campaign camera from automatically recentering while you use the diplomacy panel.

## Features

- Keep the campaign camera where it was when opening, closing, or navigating diplomacy.
- Prevent unwanted camera movement when another faction initiates diplomacy.
- Keep the manual **Select and move to faction** action available.
- Enable or disable the mod during an ongoing campaign.

## Requirements

- Total War: WARHAMMER III.
- Steam Workshop support for automatic mod installation and updates.

## Installation

Subscribe to [Disable Camera Diplomacy Focus on Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3620673720), then enable it in the game's mod manager. Steam installs and updates the packaged `.pack` file.

## Configuration

This mod has no user-facing configuration options. Enable or disable it through the game's mod manager.

## Compatibility

- The Workshop listing is updated for game version `9.x`.
- The mod does not modify game files and is described as compatible with most other mods.
- Manual camera movement to a selected faction remains available.

## Development

This repository contains the packaged `camera_lock_diplomacy.pack` file and its preview image. Mod source files and a build pipeline are not included.
